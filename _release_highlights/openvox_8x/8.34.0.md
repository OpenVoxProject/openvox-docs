Notable changes in this release:

- The bundled Ruby 3.2.11 gets fixes for seven memory-safety issues in regular expressions and in string case conversion, backported from Ruby 4.0.10 ([puppet-runtime#357](https://github.com/OpenVoxProject/puppet-runtime/pull/357)). Ruby rates three of them critical.
  The [Ruby announcement](https://www.ruby-lang.org/en/news/2026/11/18/multiple-vulnerabilities-in-regexp-and-string/) describes how each one is reached.
- Ruby 3.2 is past its end of life and has no upstream release with these fixes, so the version stays 3.2.11.
  A scanner that goes by the Ruby version can report these advisories against 8.34.0 even though the fixes are in the build.
- Nothing else changed since 8.33.1.
