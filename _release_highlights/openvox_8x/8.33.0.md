Notable changes in this release:

- The bundled multi_json gem goes back from 1.21.2 to 1.19.1, the newest version that OpenVox Server 8 can load ([puppet-runtime#333](https://github.com/OpenVoxProject/puppet-runtime/issues/333)).
  With `openvox-agent` 8.31.1 through 8.32.0 installed on a server, `require 'multi_json'` failed under `puppetserver`, and a catalog that needed the gem failed with `Error 500 on SERVER: Internal Server Error: org.jruby.exceptions.LoadError`.
  OpenVox itself does not load the gem. Server-side code that requires it was affected, directly or through a gem such as json-schema: module functions, custom types, Hiera backends, and report processors.
  Restart `puppetserver` after you upgrade the `openvox-agent` package on a server.
- The agent package ships `PowershellShim.ps1` and `PowershellShim-Helper.ps1` in its `bin` directory again ([#784](https://github.com/OpenVoxProject/openvox/pull/784)).
  Choria runs tasks that use the `powershell` input method, the default for `.ps1` tasks, through this shim. It used to come with pxp-agent, which the agent stopped shipping in 8.22.0.
- The `openvox` gem now depends on `puppet-resource_api` 1.9.2 or later in the 1.x series, the version the packages ship, instead of 2.x ([#733](https://github.com/OpenVoxProject/openvox/pull/733)).
- The `openbsd` package provider accepts a package branch that contains characters other than letters, digits, and underscores, such as `php-gd%8.4` ([#791](https://github.com/OpenVoxProject/openvox/pull/791)).
- Packages are no longer built for Ubuntu 25.04, which reached its end of life in January 2026 ([#775](https://github.com/OpenVoxProject/openvox/pull/775)). 8.32.0 is the last release in the Ubuntu 25.04 repository.
