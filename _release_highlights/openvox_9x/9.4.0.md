Notable changes in this release:

- The `openvox-agent` package is now built for Fedora 45 on x86_64 and aarch64 ([#750](https://github.com/OpenVoxProject/openvox/pull/750)).
- The agent package now ships `PowershellShim.ps1` and `PowershellShim-Helper.ps1` in its `bin` directory ([#780](https://github.com/OpenVoxProject/openvox/pull/780)).
  Choria runs tasks that use the `powershell` input method, the default for `.ps1` tasks, through this shim. It used to come with pxp-agent, which the agent stopped shipping in 8.22.0.
- The `openbsd` package provider accepts a package branch that contains characters other than letters, digits, and underscores, such as `php-gd%8.4` ([#774](https://github.com/OpenVoxProject/openvox/pull/774)).
