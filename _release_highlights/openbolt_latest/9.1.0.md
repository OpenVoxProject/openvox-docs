Notable changes in this release:

- The bundled Ruby goes from 4.0.9 to 4.0.10, which fixes seven memory-safety issues in regular expressions and in string case conversion. Ruby rates three of them critical.
  The [Ruby announcement](https://www.ruby-lang.org/en/news/2026/11/18/multiple-vulnerabilities-in-regexp-and-string/) describes how each one is reached.
- The PCP transport is back ([#385](https://github.com/OpenVoxProject/openbolt/pull/385)). It runs tasks through the Puppet Enterprise orchestrator. OpenBolt dropped it before its first stable release and brings it back for sites that are moving from Puppet Enterprise to OpenVox.
  The packages bundle the `orchestrator_client` gem that the transport needs. The `openbolt` gem does not depend on it, so with a gem install, install `orchestrator_client` yourself.
- The Choria transport fails a call whose `run-as` user is not `root` on a POSIX target, where it used to ignore the option and run as root ([#392](https://github.com/OpenVoxProject/openbolt/pull/392)).
  This covers `--run-as`, `_run_as` in a plan, and a configured `run-as` value. Choria targets that already have `run-as` set to another user now fail until you remove the option or set it to `root`.
