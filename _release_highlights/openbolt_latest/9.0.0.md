OpenBolt 9.0.0 follows 5.6.0. The version number moves from 5 to 9 so that OpenBolt and OpenVox share a major version.

Before you upgrade from OpenBolt 5.x:

- The packages are published in the `openvox9` repositories and download directories. See [Installing OpenBolt](bolt_installing.html).
- Packages are no longer built for Amazon Linux 2, Debian 11, Fedora 42, and Ubuntu 25.04. Fedora 45 is new.
- The packages bundle OpenVox 9.3.0 and Ruby 4.0.9, so plans, apply blocks, and `bolt apply` are compiled with OpenVox 9.
  See [Upgrading from OpenVox 8 to OpenVox 9](/openvox/latest/upgrade_major.html) for the language changes.
- Gems that you installed into OpenBolt's Ruby must be installed again, because the gem directory is named after the Ruby version.
- `apply_prep` installs the OpenVox 9 agent by default on a target that has no agent.
  To keep installing the OpenVox 8 agent, see [Puppet library plugins](using_plugins.html#puppet-library-plugins).
- The gem requires Ruby 3.4 or later.
- The Choria transport can upload and download files, and several of its error kinds changed. See [Choria transport](choria-transport.html).
